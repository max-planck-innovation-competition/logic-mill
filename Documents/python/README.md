# Documents — Python Example

This example demonstrates the [Documents](https://logic-mill.net/app/lm/retrieve-multiple-documents-by-ids) API endpoint of [Logic Mill](https://logic-mill.net/), which retrieves document metadata and embeddings by ID.

## Setup

1. Obtain an API key at <https://logic-mill.net/identity/api-token>.
2. Create a `.env` file in this directory:
   ```
   API_KEY=your_api_key_here
   ```
3. Install dependencies:
   ```
   pip install -r requirements.txt
   ```
4. Run the notebook with Jupyter.
