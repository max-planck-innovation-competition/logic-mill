# encodeDocument — Go Example

This example demonstrates the [encodeDocument](https://logic-mill.net/app/lm/encode-document) API endpoint of [Logic Mill](https://logic-mill.net/), which generates an embedding for a single user-supplied document.

## Setup

1. Obtain an API key at <https://logic-mill.net/identity/api-token>.
2. Create a `.env` file in this directory:
   ```
   API_KEY=your_api_key_here
   ```
3. Run with `go run example.go`.
