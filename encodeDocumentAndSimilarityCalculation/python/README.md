# encodeDocumentAndSimilarityCalculation — Python Example

This example demonstrates the [encodeDocumentAndSimilarityCalculation](https://logic-mill.net/app/lm/calculate-document-similarity) API endpoint of [Logic Mill](https://logic-mill.net/), which computes a similarity matrix between user-supplied documents.

## Setup

1. Obtain an API key at <https://logic-mill.net/identity/api-token>.
2. Create a `.env` file in this directory:
   ```
   API_KEY=your_api_key_here
   ```
3. Install dependencies:
   ```
   pip install -r requirements.txt
   ```
4. Run the notebook with Jupyter.
